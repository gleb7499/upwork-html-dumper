## Что можно вбивать в URL поиска Upwork

Параметры, поддерживаемые поиском `/nx/search/jobs/`:

| Параметр | Что делает | Пример значения |
| --- | --- | --- |
| `q` | Поисковый запрос (логика: AND/OR/NOT, кавычки, скобки) | `(Java OR Spring) NOT (php)` |
| `sort` | Сортировка | `recency`, `relevance` |
| `page` | Страница выдачи | `1` |
| `per_page` | Записей на страницу | `50` |
| `payment_verified` | Только верифицированная оплата | `1` |
| `proposals` | Диапазон числа откликов (можно список через запятую) | `0-4,5-9,10-14` |
| `hourly_rate` | Вилка ставки (для hourly-заказов) | `15-`, `15-50` |
| `amount` | Бюджет fixed-заказов | `50-`, `50-500` |
| `contractor_tier` | Уровень фрилансера | `1,2` |
| `category2_uid` | Подкатегория | `531770282580668418` (Web/Mobile/Software) |
| `t` | Часовой пояс контрактора | `0,-3` |
| `duration_v3` | Длительность контракта | `quarter`, `semester` |
| `workload` | Загрузка | `full_time`, `part_time` |
| `client_hires` | Число наймов клиента | `1-5`, `10-` |
| `job_type` | Тип оплаты | `hourly`, `fixed` |
| `job_status` | Статус заказа | `open` |

Синтаксис `q`: термин — обязательное слово; `OR` — альтернатива; `NOT (...)` — исключение; `"..."` — точная фраза; скобки группируют условия.

## Как правила связаны с нишами

- Каждая ниша из `список_ниш.md` получает URL с набором фильтров из секции «Все правила» (уровень «Фильтр») и свой поисковый запрос в `q`.
- Ниши блока C (scraping/automation): исключения только антишум (`homework, student, free, unpaid, volunteer`); стек НЕ исключаем.
- Ниши блоков A/B: исключения чужого стека допустимы (`php, python, flutter` и т.п.).
- Правила уровня «Ручной просмотр» применяются к любой выдаче любой ниши.
